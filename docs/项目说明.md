# 项目说明：RAG 智能问答系统

本项目是一个基于 Vercel AI SDK + TypeScript 的完整 RAG（检索增强生成）问答系统，前后端分离。

## 技术栈

后端使用 Express 5 + TypeScript（tsx 运行），AI 层使用 Vercel AI SDK v7：聊天模型是 DeepSeek（deepseek-chat），Embedding 模型是 SiliconFlow 的 BAAI/bge-m3（1024 维向量）。前端使用 Vite + React 19，通过 @ai-sdk/react 的 useChat 实现流式对话。

## 核心流程

整个系统分两条链路。离线摄取链路：文档上传后先按段落合并加滑窗切分成约 600 字的分块（相邻块重叠 100 字），再批量调用 bge-m3 生成向量，存入 server/data/vectors.json 的 JSON 向量库。在线问答链路：Agent 模式下模型自主决定是否调用 searchKnowledgeBase 工具，工具内部把查询向量化后做余弦相似度 Top-4 检索，阈值 0.5 过滤，命中的片段注入上下文生成带引用的回答。

## 运行方式

后端：npm run dev（3000 端口）；前端：npm run web（5173 端口，/api 自动代理）；批量摄取：npm run ingest；Agent 冒烟测试：npx tsx server/scripts/test-agent.ts。

## 项目结构

server/rag/ 目录下有五个模块：config.ts 集中配置，chunk.ts 负责分块，embed.ts 负责向量化，store.ts 负责 JSON 向量库读写，retrieve.ts 负责检索。server/api/documents.ts 提供文档的上传、列表、删除接口。
