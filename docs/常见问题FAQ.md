# RAG 系统常见问题（FAQ）

## 上传什么格式的文档？

目前支持 .txt 和 .md 两种纯文本格式，单份文档最大 2MB。PDF 解析在后续版本计划中。

## 为什么有的问题不显示引用来源？

系统采用 Agent 模式，模型会自主判断问题是否需要查知识库。像"1加1等于几"这类通用问题会直接回答，不触发检索；只有涉及文档内容的问题才会检索并展示引用来源。

## 相似度阈值是多少？为什么有时候知识库里有内容却没被引用？

向量检索的余弦相似度阈值设为 0.5。实测发现无关问题与知识库片段的相似度约 0.44，相关问题约 0.60，所以低于 0.5 的结果会被过滤。如果提问的措辞和文档差异太大，可能检索不到，可以换一种问法。

## 重复上传同一个文件会怎样？

摄取采用按文件增量替换策略：同一个文件名重复上传会先删除旧分块再写入新分块，不会产生重复数据。

## 如何删除文档？

在知识库页点击文档右侧的"删"按钮，会同时删除向量库中的分块和 docs 目录下的源文件。

## 数据存在哪里？

所有向量数据存储在 server/data/vectors.json，源文件保存在 docs/ 目录。当前是单机 JSON 存储，数据量大时可升级 LanceDB 向量数据库。
