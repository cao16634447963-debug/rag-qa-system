# RAG（检索增强生成）入门

RAG 是 Retrieval-Augmented Generation 的缩写，中文叫"检索增强生成"。它的核心思想是：让大模型在回答问题之前，先从外部知识库里检索相关资料，再把资料连同问题一起交给模型生成答案。

## 为什么需要 RAG

大模型的知识停留在训练截止日期，而且不了解私有数据。RAG 通过外部检索解决了两个问题：知识过时，以及企业内部文档无法被模型直接访问。

## RAG 的基本流程

整个流程分为两个阶段。第一阶段是离线摄取：把文档切分成小块，用 Embedding 模型把每块文本变成向量，存入向量库。第二阶段是在线问答：用户提问时，先把问题也变成向量，找出知识库里最相似的若干块，把它们填进提示词，最后由大模型生成带引用的回答。

## 向量相似度

判断"两段文字是否在说同一件事"，常用的方法是余弦相似度。两个向量方向越接近，余弦值越接近 1，代表语义越相似。常用的中文 Embedding 模型有 BGE 系列，例如 bge-m3，它输出 1024 维向量。
